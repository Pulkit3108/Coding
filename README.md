## Using This Repository

Most files are independent solutions rather than parts of one application. Read the source file before running it: input format, language version, dependencies, and the expected execution environment vary by exercise and platform.

There is no repository-wide build or test command. Compile or run an individual solution with the toolchain for its language, and use the original problem statement or course material for its input and expected behavior.

## Notes

- The repository is a learning archive. Solutions may favor clarity or a platform-specific submission format over reusable production code.
- Existing compiled files and vendored Go dependencies are preserved as historical repository content. New local build outputs are ignored.
