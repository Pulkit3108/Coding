# Contributing

This repository is a collection of independent learning exercises. Keep each change focused on one problem, example, or documentation improvement.

## Adding Or Updating A Solution

- Place a solution in the existing topic or platform directory that best matches it.
- Use a descriptive filename based on the exercise or problem name.
- Keep the original platform's expected input/output format when the code is intended as a submission.
- Add only the source and small supporting files needed to understand or run the exercise.
- Do not commit compiled executables, editor files, local caches, credentials, or generated dependency directories.

## Documentation

- Keep the root README focused on navigating the archive.
- Add setup or execution notes next to an exercise only when that exercise needs information beyond its source code or original problem statement.
- Do not claim benchmark results, completion status, or production readiness without reproducible evidence.

## Validation

Before opening a pull request, run the narrowest relevant check: compile or run the changed solution when practical, and use `git diff --check` for documentation-only changes.
